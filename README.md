# Практическая работа № 7 — Консольная утилита на Bash

Консольная утилита на языке командной оболочки Bash для вывода списка пользователей, запущенных процессов и управления потоками вывода.

## Параметры командной строки

| Короткий ключ | Длинный ключ | Описание |
|---|---|---|
| `-u` | `--users` | Выводит перечень пользователей и их домашних директорий, отсортированных по алфавиту |
| `-p` | `--processes` | Выводит перечень запущенных процессов, отсортированных по PID |
| `-h` | `--help` | Выводит справку с описанием аргументов и завершает работу |
| `-l PATH` | `--log PATH` | Замещает вывод на экран (`stdout`) выводом в файл по пути `PATH` |
| `-e PATH` | `--errors PATH` | Замещает вывод ошибок (`stderr`) выводом в файл по пути `PATH` |

## Использование

```bash
chmod +x lab7.sh
./lab7.sh --help
./lab7.sh -u
./lab7.sh --processes
./lab7.sh -u -l /tmp/users.log -e /tmp/errors.log
```
